Essential CSS

/* Required: prefers-reduced-motion reset */ @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } } /* Safe transitions — never go below 0.3s */ .interactive-element { transition: background 0.35s ease, opacity 0.4s ease; } /* Safe animation — always ≥ 0.5s duration */ .fade-in { animation: fadeIn 0.6s ease forwards; }

Do / avoid

Safe patterns

  • Fade-in on page load (0.6s+)
  • Smooth accordion expand
  • Gentle progress bars
  • Slow carousel (2s+ interval)
  • Hover color shift (0.35s)

Avoid entirely

  • Strobe / blink CSS
  • GIF loops that flash
  • Full-screen color shifts
  • Rapid background swaps
  • Auto-playing video loops
