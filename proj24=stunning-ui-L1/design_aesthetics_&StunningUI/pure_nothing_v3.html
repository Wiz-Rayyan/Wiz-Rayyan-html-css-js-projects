A brief history
1991
Tim Berners-Lee ships HTML
No styling whatsoever. Structure only. The browser could render it however it liked — and it did.
1993
Mosaic picks blue for links
Marc Andreessen's team chose blue because it was the least-used color in most documents. The decision was never formally standardised — it just stuck.
1996
CSS 1.0 arrives — and nobody uses it
The tool to override browser defaults exists. Developers ignore it for years. Table-based layouts persist through 2003.
2000
CSS resets begin the arms race
Every major framework ships a reset that first erases every browser default. Design now begins by destroying this page.
2014
Motherfucking Website ships
A satirical site that uses zero CSS. It accidentally becomes a design reference. The joke was that it loaded faster and read better than most designed sites.
2026
The aesthetic is still here
Browser defaults haven't meaningfully changed. The page you'd get with zero CSS in 2026 is nearly identical to 1996. Thirty years of decisions, perfectly preserved.
The essay
Reading mode

Choosing not to style something is not the same as having no aesthetic. It is a deliberate act of refusal — and refusal, done with intention, is one of the most powerful design tools available. This page communicates something the moment it loads: that content matters more than presentation, that the reader's browser is trusted, that nothing is being sold.

"The browser's default rendering engine is the design."

Your browser ships with a default stylesheet. It has always had one. Disc bullets become circles become squares as you nest lists — nobody designed that cascade. It was a decision someone made at a browser company in the 1990s, encoded into a specification, and now it exists in every browser on every device on earth, unchanged.

Every CSS framework ever written begins by erasing this page. * { box-sizing: border-box; margin: 0; padding: 0; } is a declaration of war against browser defaults. Tailwind's Preflight, Meyer's Reset, Normalize.css — all begin the same way: by destroying what the browser decided, so the designer can start from a controlled void.

The irony is that in trying to escape the browser's defaults, we replaced one set of arbitrary decisions with another. The browser chose 16px. We chose 14px. The browser chose Times New Roman. We chose Inter. None of these choices are more correct — they are simply more recent, and therefore more invisible.

This is the aesthetic of nothing: not absence, but honesty. The page looks like this because this is what a page looks like before anyone decides how it should look. It is the raw signal before the designer adds noise.
