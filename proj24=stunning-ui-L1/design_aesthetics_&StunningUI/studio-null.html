01 — Studio

Three rules we don't break.

01
Strip the ornament

If a detail doesn't carry load, light, or meaning, it doesn't go on the drawing. Decoration is a debt someone else pays for later.

02
Expose the structure

The beam, the grid, the joint — we build so the logic of a space is visible, not buried behind a finish.

03
Let color do the work

Red, yellow, blue, black. Color marks function and wayfinding before a single sign is printed.

04 — Process

How a project moves.

01 / BRIEF
Define the function

We start by writing down what the space must do, before drawing what it looks like.

02 / DIAGRAM
Map the logic

Flows, loads, and light get diagrammed first — the plan is a consequence, not a starting point.

03 / STRUCTURE
Grid the space

A structural grid gets set early and holds for the life of the project.

04 / BUILD
Build in the open

Materials and joints stay visible on site and in the finished building.

05 / HANDOVER
Hand over the logic

Clients get the drawings and the reasoning, so the building can be maintained on its own terms.
