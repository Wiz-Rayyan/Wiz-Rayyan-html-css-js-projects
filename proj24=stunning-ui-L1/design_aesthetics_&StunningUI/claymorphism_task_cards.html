Anatomy

.clay-card { border-radius: 28px; background: #8B5CF6; box-shadow: /* extruded edge */ 0 12px 0 #5B21B6, /* ambient blur */ 0 18px 30px rgba(0,0,0,.2), /* top gloss */ inset 0 2px 6px rgba(255,255,255,.25); } .clay-card:active { transform: translateY(6px); box-shadow: 0 4px 0 #5B21B6, 0 6px 14px rgba(0,0,0,.18); }
Hard edge shadow
0 12px 0 #5B21B6 — zero blur, darker hue. The extruded bottom face of the "clay block".
Ambient shadow
0 18px 30px rgba(0,0,0,.2) — soft blur lifts the card off the surface with a coloured aura.
Inset gloss
inset 0 2px 6px rgba(255,255,255,.25) — top highlight gives the puffy, domed feel.
Press-down
translateY(6px) with shadow collapse — card physically compresses into the surface on click.
