History of the form

Key moments in fractal mathematics

1883
Cantor set discovered
Georg Cantor describes a set of points with zero length but uncountably infinite members — the first rigorous fractal-like object.
1904
Koch snowflake
Helge von Koch constructs an infinitely long curve enclosing finite area — a curve that is continuous everywhere but differentiable nowhere.
1918
Julia & Fatou sets
Gaston Julia and Pierre Fatou independently classify the dynamics of rational maps — without computers, working purely by hand.
1975
Mandelbrot coins "fractal"
Benoît Mandelbrot publishes Les objets fractals — giving language to self-similar geometry and its presence throughout nature.
1980
First computer rendering
Mandelbrot renders the set bearing his name at IBM — the first visualisation of infinite boundary complexity via machine.
Mandelbrot iteration
z → z² + c
c fixed per pixel, z starts at 0. Colour by escape time through the complex plane.
Julia iteration
z → z² + c
Same formula — but c is fixed globally and z is the pixel coordinate. One c, infinite portraits.
Hausdorff dimension
D = log N / log s
Fractal dimension D measures how detail scales. Sierpiński triangle: D ≈ 1.585. Coastline of Britain: D ≈ 1.25.
