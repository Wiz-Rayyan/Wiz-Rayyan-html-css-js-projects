Lenis smooth scroll reference card covering key concepts, tips, and a ready-to-copy AI prompt.

CORE CONCEPTS
Library
Lenis
The most popular smooth scroll JS library — free and widely used.
Browser API
requestAnimationFrame
Fires a callback ~60× per second — how Lenis stays perfectly smooth.
Math
Easing
The curve controlling deceleration — cubic-bezier controls the feel.
Interpolation
lerp
Linear interpolation — blends current scroll position toward the target.
Integration
GSAP compatibility
Lenis passes its scroll position to GSAP so ScrollTrigger still works.
TIP
Smooth scroll is a feel upgrade, not visual. Users may not notice consciously, but the site feels premium. It's one of the cheapest ways to add a high-end polish. However — never apply it to pages with fixed-height modals or overflow:hidden sections, as it can cause visual glitches.
AI PROMPT TO USE
Add Lenis smooth scrolling to this website. Import from CDN. Initialize with: const lenis = new Lenis({ duration: 1.2, easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), smooth: true }); Run in animation loop: function raf(time) { lenis.raf(time); requestAnimationFrame(raf); } requestAnimationFrame(raf); If GSAP ScrollTrigger is used, also add: lenis.on('scroll', ScrollTrigger.update) gsap.ticker.add((time) => { lenis.raf(time * 1000) })
